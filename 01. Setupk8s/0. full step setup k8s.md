## Step 3: Set hostnames and `/etc/hosts`

Set a unique hostname on every server and add all node IP addresses and
hostnames to `/etc/hosts`.

## Step 4: Install containerd

Run this script on every node:

```bash
#!/usr/bin/env bash

# sysctl parameters required by Kubernetes
cat <<EOF | sudo tee /etc/sysctl.d/k8s.conf
net.ipv4.ip_forward = 1
EOF

# Apply sysctl parameters without rebooting
sudo sysctl --system
sudo apt-get update
sudo apt-get install -y containerd

# Create the containerd configuration
sudo mkdir -p /etc/containerd
containerd config default | sudo tee /etc/containerd/config.toml
sudo sed -i \
  's/SystemdCgroup = false/SystemdCgroup = true/g' \
  /etc/containerd/config.toml
sudo systemctl restart containerd
```

## Step 5: Install Kubernetes components

Run this script on every node:

```bash
#!/usr/bin/env bash

sudo apt-get update
sudo apt-get install -y apt-transport-https ca-certificates curl gpg

curl -fsSL https://pkgs.k8s.io/core:/stable:/v1.36/deb/Release.key \
  | sudo gpg --dearmor \
    -o /etc/apt/keyrings/kubernetes-apt-keyring.gpg

echo "deb [signed-by=/etc/apt/keyrings/kubernetes-apt-keyring.gpg] \
https://pkgs.k8s.io/core:/stable:/v1.36/deb/ /" \
  | sudo tee /etc/apt/sources.list.d/kubernetes.list

sudo apt-get update
sudo apt-get install -y \
  kubelet=1.36.0-1.1 \
  kubeadm=1.36.0-1.1 \
  kubectl=1.36.0-1.1
sudo apt-mark hold kubelet kubeadm kubectl
```

## Step 6: Initialize the Kubernetes cluster

Run on the control-plane node:

```bash
kubeadm init
```

Configure the `kubectl` kubeconfig:

```bash
mkdir -p ~/.kube
sudo cp -i /etc/kubernetes/admin.conf ~/.kube/config
sudo chown "$(id -u):$(id -g)" ~/.kube/config
```

## Step 7: Install Cilium

Install the Cilium CLI:

```bash
CILIUM_CLI_VERSION=$(
  curl -s https://raw.githubusercontent.com/cilium/cilium-cli/main/stable.txt
)
CLI_ARCH=amd64
if [ "$(uname -m)" = "aarch64" ]; then
  CLI_ARCH=arm64
fi

curl -L --fail --remote-name-all \
  "https://github.com/cilium/cilium-cli/releases/download/\
${CILIUM_CLI_VERSION}/cilium-linux-${CLI_ARCH}.tar.gz"{,.sha256sum}
sha256sum --check "cilium-linux-${CLI_ARCH}.tar.gz.sha256sum"
sudo tar xzvfC "cilium-linux-${CLI_ARCH}.tar.gz" /usr/local/bin
rm "cilium-linux-${CLI_ARCH}.tar.gz"{,.sha256sum}
```

Install Cilium:

```bash
cilium install --set \
  ipam.operator.clusterPoolIPv4PodCIDRList="10.0.0.0/9"
```

## Step 8: Join worker nodes

Create the join command on the control-plane node:

```bash
kubeadm token create --print-join-command
```
